# KAIRO // Systems & Environment Dev

Single-file dark editorial Roblox developer portfolio built with Tailwind CSS (CDN), Google Fonts (`Space Grotesk` + `JetBrains Mono`), bespoke animated technical SVG schematics, and vanilla JavaScript.

## Live Demo

- **Production**: https://kairo-portfolio-sandy.vercel.app

## Features

- Matte dark Swiss-grid layout (`#09090B` / `#111113` / `#222225`) with restrained `#CCFF00` accent indicators and subtle SVG noise grain overlay.
- Sticky minimal header with scrollspy navigation (`Work`, `Stack`, `Rates`) and one-click Discord handle copy (`kairo.dev`) with toast notification.
- Asymmetric hero section with live commission status pill, isometric wireframe telemetry dossier, and 3-column metrics strip.
- Interactive Bento work grid with category filtering (`ALL`, `SCRIPTING`, `BUILDING`, `UI`), 4 bespoke hover-animated technical SVG schematics (zero external images), and accessible project detail modal (`ESC`, close button, backdrop click).
- Engineering stack matrix, 3-column capabilities & rates strip (USD & DevEx-equivalent Robux), and footer Discord copy bar.

## Local Usage

Open `index.html` directly in any modern browser — no build step required.
